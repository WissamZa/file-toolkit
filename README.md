# File Toolkit

A single-file, menu-driven CLI for organizing photo/PDF folders: create dated
folders, index files into a SQLite database, compile each folder's images and
PDFs into one combined PDF, hard-link the compiled PDFs into a central
directory, and export specific files — all from one interactive menu.

## Features

- **Day folders** — creates `01-MM-YYYY` through `31-MM-YYYY` folders for a
  given month/year in one go.
- **Indexing** — scans the current directory tree and records every
  `.jpg` / `.jpeg` / `.png` / `.pdf` file into a local `files.db` SQLite
  database.
- **Export** — copies out specific indexed files (e.g. every `0.jpeg`) into
  an `export_output/` folder with folder-prefixed names.
- **Build PDFs** — compiles each folder's images (and any source PDFs) into
  one borderless PDF, sorted in natural order (`0, 1, 2 … 10`, not
  `0, 1, 10, 2`). PDFs previously generated by this tool are automatically
  skipped so they're never re-ingested as source material.
- **Hard-link PDFs** — hard-links every compiled folder PDF into a central
  `pdf/` directory for easy browsing.
- **One-click pipeline** — runs Index → Build PDFs → Hard-link in sequence.

## Requirements

- Python 3.9+
- [reportlab](https://pypi.org/project/reportlab/)
- [pypdf](https://pypi.org/project/pypdf/)

### Setup with uv (recommended)

This project is configured for [uv](https://docs.astral.sh/uv/). From the
repo root:

```bash
uv sync
```

This creates a `.venv` and installs all dependencies pinned in
`pyproject.toml` / `uv.lock`. Run the tool with:

```bash
uv run file_toolkit.py
```

### Setup with pip (alternative)

```bash
pip install reportlab pypdf
```

## Usage

Run the toolkit from the directory containing your folders of images/PDFs:

```bash
python file_toolkit.py
# or, with uv:
uv run file_toolkit.py
```

You'll see a menu:

```
==================== File Toolkit ====================
 1) Create day folders (01-MM-YYYY .. 31-MM-YYYY)
 2) Index files into database
 3) Export files (copies every 0.jpeg)
 4) Build PDFs from indexed folders
 5) Hard-link compiled PDFs into ./pdf
 6) One click: Index -> Build PDFs -> Hard Link
 0) Exit
========================================================
```

Pick an option by number and follow the prompts.

### Typical workflow

1. **Create folders** for the month you're working with (option 1).
2. **Drop your images/PDFs** into the generated `DD-MM-YYYY` folders.
3. **Index** the files (option 2), or just run the **one-click pipeline**
   (option 6) to index, build PDFs, and hard-link everything in one step.

## Notes

- `files.db` is created in the current working directory and is reused
  across runs — re-indexing only adds new files, it won't duplicate entries.
- The `export_output` and `pdf` folders (and the `files.db` file itself)
  are excluded from indexing/build steps so the tool never processes its
  own output as source material.
